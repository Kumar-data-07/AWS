# 🌍 Global Forest Data Analysis Using AWS

## 📌 Project Overview

The Global Forest Data Analysis project focuses on analyzing global forest data to understand forest coverage, trends, and changes across different countries and years.

AWS cloud services were used to store, query, and analyze the dataset. The analyzed data was then visualized using Microsoft Power BI to create an interactive dashboard.

This project demonstrates the practical use of cloud computing, SQL, data analytics, and data visualization for environmental data analysis.

---

## 🎯 Objectives

- Analyze global forest data across different countries and years.
- Store and manage the dataset using AWS.
- Perform SQL-based analysis using Amazon Athena.
- Identify forest coverage trends and changes.
- Create meaningful visualizations using Power BI.
- Generate insights from environmental data.

---

## 🛠️ Technologies Used

- ☁️ Amazon S3
- 🔎 Amazon Athena
- 🗄️ SQL
- 📊 Microsoft Power BI
- 🐍 Python / Jupyter Notebook
- 📁 CSV Dataset

---

## ☁️ AWS Workflow

The project follows this workflow:

Dataset → Amazon S3 → Amazon Athena → SQL Analysis → Power BI → Dashboard

### AWS Services

**Amazon S3**
- Used to store the forest dataset in the cloud.

**Amazon Athena**
- Used to query and analyze the dataset using SQL.

**Power BI**
- Used to create interactive charts and dashboards from the analyzed data.
